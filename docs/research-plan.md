# Research plan

Goal: test reproducible hypotheses about micro-to-macro emergence rather than generate unsupported claims about fundamental physics.

First benchmark: 2D periodic ferromagnetic Ising model, J = k_B = 1, with critical infinite-volume temperature 2/log(1+sqrt(2)). Compare measured ordering and finite-size behavior against known results. This first version does **not** calculate error bars or establish a phase transition.

Next milestones: statistical uncertainty, finite-size scaling, alternate baselines, model-selection criteria, and eventually local rules for emergent graph geometry and causal propagation. Formalize suitable invariants in Lean only when the relevant definitions and mathematical claims are precise.
